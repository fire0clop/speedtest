# speedtest

Консольный скрипт на Python, который замеряет скорость скачивания с указанного адреса.

Скрипт делает к адресу 10 запросов **последовательно**, каждый раз дочитывает ответ до конца, а затем печатает:

- среднее время одного запроса (в секундах);
- общий объём скачанных данных (в мегабайтах и байтах);
- скорость скачивания.

## Единицы измерения

| Величина            | Единица                                  |
|---------------------|------------------------------------------|
| Скорость скачивания | **Мбит/с** (мегабиты в секунду), 1 Мбит = 1 000 000 бит |
| Объём данных        | МБ, 1 МБ = 1 000 000 байт                 |
| Время               | секунды                                  |

Мбит/с выбраны потому, что в них же указывают скорость интернет-провайдеры и сервисы вроде speedtest — результат легко сравнить с тарифом.

Скорость считается как `весь объём в битах / суммарное время всех запросов`. Время запроса — от его отправки до получения последнего байта ответа (включает DNS, установку соединения и TLS, поэтому на маленьких файлах скорость будет занижена — для замера лучше брать файл от нескольких мегабайт).

## Требования

Python 3.9+. Сторонние библиотеки не нужны — используется только стандартная библиотека (`urllib`, `ssl`, `time`, `argparse`). Пакет `certifi` необязателен (см. ниже про SSL на macOS).

## Запуск

```bash
git clone https://github.com/fire0clop/speedtest.git
cd speedtest
python3 speedtest.py <URL>
```

Пример:

```bash
python3 speedtest.py https://proof.ovh.net/files/10Mb.dat
```

Вывод:

```
Запрос  1:    10.49 МБ за 11.903 с
Запрос  2:    10.49 МБ за 10.583 с
...
Запрос 10:    10.49 МБ за 10.921 с

Среднее время запроса: 10.702 с
Всего скачано:         104.86 МБ (104857600 байт)
Скорость скачивания:   7.84 Мбит/с
```

### Ошибка `CERTIFICATE_VERIFY_FAILED` на macOS

Python, установленный с python.org, по умолчанию не видит системные сертификаты. Скрипт сам подхватит их из пакета `certifi`, если он установлен:

```bash
pip3 install certifi
```

(или запустите `Install Certificates.command` из папки `/Applications/Python 3.x/`).

### Параметры

| Параметр            | Что делает                          | По умолчанию |
|---------------------|-------------------------------------|--------------|
| `url`               | адрес, к которому делать запросы    | обязательный |
| `-n`, `--requests`  | число запросов                      | 10           |
| `-t`, `--timeout`   | таймаут одного запроса, в секундах  | 30           |

Если какой-то запрос завершился ошибкой (нет сети, HTTP 404, таймаут), скрипт выводит её и завершается с кодом 1.
